# DeathRoll Enhancer on WoW Forever

Audit of the local v2.4.2 development checkout on 22 November 2026. The installed Forever client reports **1.60.1.71037**. Its addon directory is a junction to this checkout. Findings apply to those working files, including the unpublished UI and invitation changes.

## Resolution in the Forever dev checkout

The invitation, history, trade ownership, stats audience, Group roster, and performance findings below now have fixes in the dev checkout. Both players need the updated dev build for silent invitations. The recipient sees the host’s fixed wager or trade settlement terms before accepting. Unrelated confirmations keep ownership of their buttons.

The dev ZIP includes the table artwork. Both ZIP variants have been exercised in a clean Lua client harness with their embedded Ace3 libraries, empty SavedVariables, and the Forever manifest. Automated coverage includes the Windows copper limit, retargeting and delayed nameplate identity, and the Korean roll particle.

Still pending in a live two-account session are actual message delivery, last-second trade edits and cancellation, challenger animation and controller dismissal, and a localized system roll. The sections below preserve the original findings and reproduction conditions.

## Start with the invitation and payout contract

| Priority | What a player can observe | Evidence and smallest useful change |
|---|---|---|

## History, Group, and performance

The stored payment and totals return to 0g, and the pending debt has already been consumed. Reproduced in the Lua harness. | Reread the record by ID at save time. Apply only the fields the user edited and surface a conflict if both paths changed the wager. [Editor inputs](../Core.lua#L2820) · [Save callback](../Core.lua#L2932) |
| **High: saving an older win can turn it into a loss.** A legacy `WIN` worth 5g appears as won in History but opens as Lost in the editor. In a simulated character switch within five minutes, a 7g trade with the same opponent credited the first character's row. | Keep aggregate history shared if desired. Put the local character's full identity on unsettled debts and use it when matching, restoring and marking them for group review. Leave ownerless legacy debts for manual assignment. [Profile creation](../Core.lua#L156) · [Pending wager](../Core.lua#L3234) |
| If the current trade partner is unreadable at trade open, a stale recipient label can credit the previous partner. | A later roll in another range can hide a valid accepted opener that still exists in the cache. | After a tracked duel, merge the opponent's history into a new name and then pay under that name. The saved wager can settle while the open Duel screen says tracking closed. A separately identifiable dev-enabled test package would simplify two-player testing. [Builder](../scripts/build_release.py#L57) · [Manifest tests](../tests/test_package.py#L68)
- A locally built **2.4.3-beta.1** ZIP reported **2.4.2** after loading its packaged Core module. Global version substitution replaces both the placeholder and the code that checks for an unresolved placeholder. Fix that comparison and execute packaged code in the version test. The release workflow also publishes a beta tag as a regular GitHub release unless it is passed the prerelease flag. [Runtime version](../Core.lua#L50) · [Substitution](../scripts/build_release.py#L65) · [Release workflow](../.github/workflows/release.yml#L64)
- The working checkout contains the new gold artwork, but the files are untracked. The local builder includes media present on disk, and the package test specifically requires only the logo. Before distributing the new UI, include the runtime assets and assert the gold table and glint textures exist in the resulting ZIP. [Texture references](../TableUI.lua#L6) · [Package test](../tests/test_package.py#L23)
- The pinned Ace3 revision already includes Forever surname and ruleset fixes. Upstream master was two commits ahead at review time, addressing checkbox description clipping and container width calculations. These are targeted UI upgrades. Preserve the documented local Heading compatibility patch on any update. [Embedded provenance](../Libs/SOURCES.txt) · [Checkbox fix](https://github.com/WoWUIDev/Ace3/commit/ed37304bfd908c3fc82387e02adc2309829e1f16) · [Layout fix](https://github.com/WoWUIDev/Ace3/commit/075bafb435f950f940e10c620510b3bd66ec9695)
